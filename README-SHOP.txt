nibba - SHOP (paints, hardware, interior, household)
====================================================
DAILY USE (only 4 steps):
1. Double-click the "nibba Shop" icon on the Desktop.
2. Login with your username + PIN.
3. PURCHASE when stock arrives (from supplier), SALE when it sells
   (to customer). Balance updates by itself.
4. When done: open the "nibba Close" icon (stops the server quietly).

FIRST DAY (owner, 5 minutes):
- Login: owner / 1234, then change the PIN immediately
  (Settings -> Staff -> change).
- Add your Materials with units (bags, pcs, ltr, mtr) from the menu.
- Add one test purchase + one sale, check the balance.

MONTHLY EXCEL FILES (automatic):
- Every opening saves this month's sales and purchases as Excel
  into the Data folder: Data/2026-10/sales.xlsx and purchases.xlsx
  (with per-material totals). Open and work on them directly.
- Once a month, copy the Backup AND Data folders to a pen drive.

BACKUP (automatic):
- Every opening saves a Backup copy. Once a month, copy the
  Backup folder to a pen drive.

SUPPORT:
- Updates: Help page shows the version and an Install button when
  a new version is ready. One click — the app updates and restarts
  itself. Saved stock is never touched.
- If the page does not open: double-click "nibba Close", wait
  10 seconds, open "nibba Shop" again. Still stuck: call support,
  say exactly what you see on screen.
